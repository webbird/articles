# articles

Seitenmodul für WBCE 1.7 mit Artikeln, Bildern, Gruppen und Tags, der Nachfolger von `news_img`. Es läuft parallel zu `news_img` und übernimmt dessen Inhalte per Import.

- Artikel mit Vorschaubild, Galerie, Zeitraum, Gruppe und Tags
- Views `default`, `grid` und `avatar`, Galerien Fotorama, Masonry und Tobii
- Import aus `news_img`, Topics und anderen `articles`-Abschnitten, dazu zwei Demo-Pakete
- Droplets für Artikellisten und Slider, RSS-Feed, Links per `[articles:NN]`
